# `results.h5`: проверка формата по реальным данным

Статус: **черновик**. Это наблюдательная/читательская записка — не замена
спецификации.

**Оригинал (источник истины):** [`docs/hdf5_schema.md`](hdf5_schema.md).
Он описывает формат со стороны продюсера (`hdf5_writer.f90`,
`hdf5_manager.f90`) и является каноном. Этот файл лишь фиксирует то, что
удалось **подтвердить или уточнить** инспекцией реальных HDF5-файлов, и
содержит заметки для кода-ридера. При расхождении — верить оригиналу.

Смежные документы: [`docs/results_h5.md`](results_h5.md) (черновик
читательской спеки, частично пересекается), [`docs/elmfire_h5.md`](elmfire_h5.md).

## 1. Что именно проверялось

Прогон серии по `nphi`:

- `data/wave2d/FT2/2026-09-23_18-04-16/results.h5` — **общий** файл серии;
- `data/wave2d/FT2/2026-09-23_18-04-16/tasks/nphi+122/results.h5` — файл
  отдельной задачи.

Параметры сетки этого прогона (не хардкодить, читать из
`/run_params/w2grid`): `Nr = 51`, `Msmax = 128`, `Nrmargin = 56`,
`Mmax = 16`. Серия: `nphi1 = 122`, `nphi2 = -122`, `nphistep = -61`
(пять мод: `+000`, `+061`, `+122`, `-061`, `-122`).

Инструмент: `uv run python` + `h5py`.

## 2. Что подтвердилось

- Набор групп и датасетов **полностью совпал** со структурой из оригинала:
  `run_info/system`, `run_params/{w2grid,plasma,temperature,kngrid,density}`,
  `coord/{rho,X,Y}`, `nphi*/field_2D/{Ex,Ey,Ez,Ea}`, `flux_surf_2D`,
  `plasma_par_2D`, `magnt_fld_2D`, `di_tensor_2D`, `resonance_2D`,
  `geometry_2D`, `wkb_2D`. Лишних датасетов не найдено.
- Типы: вещественные — `float64`, комплексные — `complex128`.
- Порядок осей `(Nr, Msmax)`: ось 0 — радиальный индекс, ось 1 — полоидальный.
- `coord/rho` имеет длину `Nrmargin` (`56 = 51 + 5` margin).
- Разделение «файл задачи vs общий файл серии» (раздел «Общий файл для серии
  по `nphi`» оригинала) наблюдается вживую: в файле задачи ровно одна группа
  `/nphi*`, в общем — пять, а `run_params/w2grid` в общем файле содержит
  диапазон всей серии.

## 3. Уточнения и подводные камни

Всё ниже — наблюдения поверх оригинала, полезные ридеру.

1. **Незаполненные точки = `0`, а не `NaN`.** Оригинал говорит «не заполнены».
   Фактически это нули: проверка `numpy.isnan` бесполезна, нужно сравнивать
   с `0`. Это относится к строке `ir = 0` и к опциональным `<group>/X,Y`.
2. **Магнитная ось (`ir = 0`) неоднородна по группам** (оригинал предупреждает
   «не использовать без проверки», здесь — конкретика для этого прогона):
   - `wkb_2D/Nrho1, Nrho2` — вся строка `ir = 0` равна `0+0j` (на оси не
     считается);
   - `flux_surf_2D/psi, theta_deg` — на оси не нули, а машинный мусор
     порядка `1e-11…1e-13` (физически `≈0`, нормированный радиус оси);
   - `magnt_fld_2D`, `geometry_2D`, `resonance_2D`, `di_tensor_2D` — на
     `ir = 0` ненулевая **только первая полоидальная точка**, остальные `0`;
   - **`plasma_par_2D` — исключение.** На `ir = 0` в столбцах `1…127` лежат
     не нули, а «мусор» (линейные рампы: `Te = 45, 64.7, 84.4, …`,
     `ne = 36.6, 56.25, …`). Осмысленна только колонка `0`
     (`Te = 0.5 = Te0`, `Ti = 0.001 = Ti0`, `ne = 20 = de0`). При чтении оси
     брать лишь `ir = 0, itheta = 0`, иначе значения недостоверны.
3. **Типы атрибутов `run_params/w2grid` зависят от файла.** В общем файле
   серии `nphi1/nphi2/nphistep` имеют тип `int64`, в файле задачи — `int32`
   (`nphi1 == nphi2 == <мода>`, `nphistep = 1`). Остальные атрибуты `w2grid`
   — `int32`. `Nymax`, `Nzmax` в `kngrid` — `float64`, хотя по смыслу это
   границы. Тип атрибутов при чтении не предполагать, а брать `int(...)`.
4. **Размеры сетки различаются между прогонами** — `Nr`, `Msmax`, `Nrmargin`
   нельзя хардкодить (в этом прогоне `51/128/56`, в других — иные). Форму
   массивов всегда выводить из `/run_params/w2grid`.

## 4. Как читать (пример)

```python
import h5py
import numpy as np

path = ".../results.h5"
with h5py.File(path, "r") as f:
    nr = int(f["run_params/w2grid"].attrs["Nr"])
    ms = int(f["run_params/w2grid"].attrs["Msmax"])

    # полоидальные моды берём по атрибуту, а не по имени группы
    modes = {int(f[g].attrs["nphi"]): g for g in f if g.startswith("nphi")}

    # ось (ir=0) недостоверна, кроме точки itheta=0 — не читать без проверки
    Ex = f[f"{modes[122]}/field_2D/Ex"][nr, ms]  # complex128

    # геометрия общая для всех мод — только из /coord
    X, Y, rho = f["coord/X"][()], f["coord/Y"][()], f["coord/rho"][()]
```

Пути к данным в проекте — только через `src/common/paths.py`
(см. `AGENTS.md`), не хардкодить `results.h5`.
