# Спецификация формата `z1.h5` (ELMFIRE)

Статус: **черновик-заглушка**. Формат ELMFIRE намеренно ещё **не изучен** —
это отдельная задача «на потом». Документ заполнить по образцу
[`docs/results_h5.md`](results_h5.md), когда дойдём до ELMFIRE.

## Что известно сейчас (не проверено)

Сведения ниже взяты из кода (`converter_to_hdf.py`) и черновых заметок, но
**не подтверждены** инспекцией реального `z1.h5`. При изучении формата всё
перепроверить и заменить на факты.

```
/rho_mesh/rho       (121,)        1D радиусы (в исходнике — сантиметры?)
/rho_mesh/N_theta   (121,)        число угловых точек на радиус
/time_indices       (945,)
/time_values        (945,)        физическое время
/fluctuations       (945,121,600) (time, rho, theta), float32, gzip
```
