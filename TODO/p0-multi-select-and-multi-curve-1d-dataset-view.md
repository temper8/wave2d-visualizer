# Наложение нескольких 1D-рядов (multi-select и общий слой)

- **Приоритет:** P0
- **Статус:** todo
- **Зависит от:** [done/2026-10-14-extend-1d-dataset-view-with-axes-and-multiple-curves.md](done/2026-10-14-extend-1d-dataset-view-with-axes-and-multiple-curves.md)

- **Файлы:** `src/wave2d/renderers.py`, `src/wave2d/h5tree.py`,
  `src/wave2d/datasetview.py`, `src/wave2d/viewer.py`

## Контекст

В F1 (см. зависимость) 1D-режим `DatasetView` получил оси, подписи и
комплексный рендер-заглушку, но по-прежнему рисует **один** ряд. Полезные
радиальные профили идут родственными группами — `/power_balance/nphi*/`
`p_ld`/`p_tt`/`p_mx`, `dP*_dpsi` и т.п., — и их хочется видеть вместе.

Тот же слой наложения нужен **MultiView**
([p2-multiview-compare-runs.md](p2-multiview-compare-runs.md)): 1D-вкладка
сравнивает одноимённые ряды из **разных** прогонов. Поэтому рендер нескольких
кривых выносится в общий `renderers.draw_curves`, а не живёт только внутри
`DatasetView`; 2D-часть — отдельная задача
[p2-multiview-2d-grid-rendering.md](p2-multiview-2d-grid-rendering.md).

Смена контракта — ключевая сложность: сейчас `on_select(path)` и
`DatasetView.show(Selection)` работают с одним узлом. Multi-select требует
списка и согласованного поведения для разнородных выборок.

## Шаги

- [ ] **Выбрать источник рядов.** Предпочтительно — multi-select в
      `H5TreeView`: `selectmode="extended"`, `on_select` отдаёт список путей,
      `DatasetView.show(list[Selection])`. Альтернатива — ограничиться
      `real/imag/abs` (уже закрыто в F1) и не менять контракт. Решение
      зафиксировать здесь перед реализацией.
- [ ] **Модель выбора.** Расширить `Selection`/`show` до списка (или ввести
      `Selection`-группу). Обратная совместимость: одиночный узел — список из
      одного элемента.
- [ ] **Общий слой наложения.** `renderers.draw_curves(ax, series, *, xlabel,
      ylabel)`: несколько линий + легенда (серия = `(x, y, label, color)`);
      переиспользуется `DatasetView` и `MultiView`.
- [ ] **Наложение 1D + легенда в `DatasetView`.** Подписи — имя датасета +
      `units`; оси `rho`/`psi`/`index` применяются, если совпадают по длине у
      всех рядов (или приводятся к общему x — решить).
- [ ] **Smoke вручную.** Выбрать `p_ld`/`p_tt`/`p_mx` (Ctrl в дереве) →
      наложение с легендой; проверить отсутствие регрессий при одиночном
      выборе и в режимах 2D/attrs/message. При появлении `pytest` (P5) —
      тесты на диспетчер режимов без Tk.

## Критерии готовности

- Несколько однотипных 1D-рядов рисуются вместе с легендой и общими осями.
- `draw_curves` пригоден к переиспользованию в `MultiView`.
- Одиночный выбор, 2D/attrs/message — без регрессий.
- Поведение при разнородном/неподдерживаемом выборе определено и не роняет
  окно.

## Риски / открытые вопросы

- **Смена контракта** затрагивает `H5TreeView`, `viewer.py` и `DatasetView` —
  делать инкрементально, сохраняя одиночный путь как частный случай.
- Единицы и нормировка `rho`/`psi` ещё не подтверждены физиком
  (`docs/results_h5.md`, §11) — при наложении рядов с разными единицами это
  станет заметнее.
