## Контекст

Сейчас «единица просмотра» — один `W2DViewer` (один `results.h5`): дерево
`H5TreeView` + один `DatasetView`. Сравнить поля/профили из **разных расчётов**
(разные `<case_id>/<stamp>` или разные `tasks/<nphi>`) нельзя — приходится
открывать окна по отдельности и сверять глазами.

**Идея.** В обычном просмотрщике появляется кнопка **«В сравнение»**, которая
отправляет **текущий график** в общее окно **MultiView**, где собранные графики
показываются вместе. Кнопка может быть в нескольких открытых окнах — все
складывают элементы в один и тот же MultiView.

Это то же наложение, что и в P0, но **между файлами**; поэтому общий
рендер-слой (несколько кривых + легенда + общие оси) делается один раз в P0,
а здесь добавляется межоконный источник выбора и 2D-раскладка.

**Группировка по имени.** Сравнивать имеет смысл одноимённые датасеты,
поэтому MultiView — панель вкладок (`ttk.Notebook`): одна вкладка = одна
группа одноимённых датасетов. Добавляемый датасет кладётся в вкладку со своим
именем, а если такой вкладки нет — она создаётся.

## Черновые решения (уточнить до кода)

- **Один общий MultiView на приложение** («соответствующий multiview»), окно
  `Toplevel` создаётся при первом добавлении и живёт до закрытия.
- **Ключ группы — имя датасета** (лист пути, напр. `Ea`) — решено; заголовок
  вкладки — имя (+ счётчик элементов). Подпись элемента внутри вкладки — метка
  источника + **полный** путь узла, напр.
  `FT-2_LH_smoke_nphi/2026-09-29_13-56-49 [tasks/nphi+122] /fields/nphi+122/Ea`.
  Одноимённые узлы из разных веток (`/input/rho` vs `/grid/rho`) попадают
  в одну вкладку и различаются полным путём в подписи.
- **Новая вкладка** создаётся автоматически при добавлении датасета, чьего
  имени ещё нет среди групп.
- **Повторное добавление** того же (источник + имя): черновой вариант —
  заменять существующий элемент, а не дублировать.
- **`PlotItem` хранит снимок** `data`/`attrs` — решено: не зависит от жизни
  `H5Reader` и доступности сетевой шары; 1D — копейки, 2D ~0.8 МБ. Ленивое
  чтение по ссылке — позже.
- **MVP без реального рендера:** содержимое вкладки — **текстовый список**
  добавленных графиков (имя + метка источника), а не overlay/grid. Реальная
  отрисовка — отдельным шагом позже.
- **Кнопка «В сравнение»** — в той же строке переключателей, но **справа**
  (`side=tk.RIGHT`); пересоздаётся вместе с `controls`, активна в `1d`/`2d`.
- **Идентичность элемента** — `(file_path, node_path)`; повторное добавление
  обновляет элемент на месте.
- **Жизненный цикл** — одно общее окно; при закрытии набор сохраняется
  (переоткрытие восстанавливает), сброс — кнопкой «Очистить».
- **Смешанные 1D+2D** — предупреждение; одноимённые датасеты разных типов
  тоже предупреждаем и **не** добавляем; как поступать в реальности — решим,
  когда встретимся (пока не знаем).

## Шаги (MVP)

- [ ] `PlotItem` (dataclass): `source`, `file_path`, `node_path`, `view`/`comp`,
      `data`/`attrs` (**снимок**), `color`; `name` = лист `node_path`.
- [ ] `ComparisonSet`: группы по имени, `add`/`remove`/`clear`, подписка на
      изменения (один экземпляр на приложение); `add` создаёт группу, если
      имени ещё нет; результат `created`/`added`/`replaced`/`type_conflict`.
- [ ] `MultiView` (окно `Toplevel` + `ttk.Notebook`): вкладка на группу, в
      вкладке — **текстовый список** добавленных графиков (имя + метка
      источника) с удалением; кнопка «Очистить».
- [ ] Кнопка «В сравнение» в строке `DatasetView.controls` **справа**
      (`side=tk.RIGHT`) с колбэком наружу; в `W2DViewer` — привязка к
      `ComparisonSet` через `add_to_comparison`.
- [ ] Окно создаётся при первом добавлении, переиспользуется, при закрытии
      набор сохраняется.
- [ ] Метка источника: вывести `run_id` из пути (через `Wave2DNavigator`), с
      учётом `tasks/<task>`; до P4 — best-effort по пути.
- [ ] `w2d_multiview.py` — точка входа для пустого окна (опционально).
- [ ] Обновить `TODO/README.md` и, при изменении формата/провенанса, доки.

## Риски

- **Единицы** (P0/P9): сравнение профилей из разных расчётов требует
  согласованных единиц — см. известный подводный камень в `AGENTS.md`.
- **Недоступные файлы** (сетевая шара): ленивое чтение должно деградировать
  мягко; доступность — через `src/common/fsprobe`.
- **Память** для 2D-полей: кэш на элемент, но не грузить `results.h5` целиком.
- **Жизненный цикл** общего окна: закрытие MultiView и закрытие viewer'ов не
  должны оставлять висячих ссылок/колбэков.
